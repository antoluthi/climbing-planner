Mascotte · piste retenue

Caillou.
Un compagnon de pause.

Un galet de bloc — patiné, asymétrique, traversé par la lumière. Il occupe les micro-temps morts de l'app : sync Supabase, magic link envoyé, jour de repos, état vide. Sa présence est discrète et lente ; il ne distrait jamais d'un workflow actif.

Tout ce qui suit est calé sur les tokens du thème (cuivre #e0a875 en sombre, terre brûlée #8b4c20 en clair) et la famille type Newsreader + Inter.

02 · Construction

Anatomie du caillou

SVG vectoriel · ~9 ko

Chaque détail vise un caillou qui semble posé là — pas dessiné. La silhouette est volontairement asymétrique ; les textures de surface se réveillent les unes après les autres à mesure qu'on zoome.

1

Silhouette asymétrique

Tracée en courbes de Bézier libres, jamais miroir. Le sommet est plus haut côté gauche pour suggérer un caillou posé naturellement, pas une forme géométrique.

2

Yeux dans la matière

Posés dans de légères indentations (ellipse sombre semi-transparente). Pas de blanc d'œil — l'iris noir profond avec un reflet chaud lit comme une présence, pas un personnage cartoon.

3

Texture multi-couches

Dégradé radial principal + patches d'ombre/lumière + mouchetures claires et sombres + une faille fine + grain SVG. Tout est dans le caillou via clip-path, jamais par-dessus.

4

Ombre vivante

L'ombre au sol respire avec lui (X scale, opacité). Elle ancre le caillou et évite l'effet "détouré" sur les arrière-plans clairs comme sombres.

03 · Catalogue d'animations

Huit états, du veille au repos

Tous > 2,5s · sans saccade

Aucune animation ne dure moins de 2,5 secondes. Les clignements sont rares (8–10s) et lents (~250 ms). Les déplacements de pupille font moins de 2 pixels. Tout respecte prefers-reduced-motion.

015,4s · loop

Idle — respiration

État par défaut. Légère pulsation Y (1,012 / 0,992). Clignement toutes les 8,4s. Pupilles glissent dans une plage de ±1,5 px sur 11s.

026,8s · loop

Sommeil

Paupières basses dessinant un croissant. Respiration ralentie. Trois "z" italiques (serif Newsreader) montent en décalé toutes les 4,2 s.

032,6s · loop

Chargement

Trois galets satellites en orbite, légèrement décalés (rotation continue). Respiration de fond inchangée. Lisible à 48 px comme à 200 px.

041,4s · once

Succès

Rebond squash & stretch léger. Sourire qui s'étire (mouth scaleY × 1.6). Trois étincelles cuivre apparaissent puis disparaissent. Retour à idle.

050,6s · once

Erreur

Tremblement contenu (±2 px). Sourcils froncés qui descendent et restent. Pas de couleur rouge — la couleur d'accent reste celle du thème.

066s · loop

Curieux — vide

Pour les empty states. Regard fixé vers le haut-droit, dérive lente vers l'autre côté. Suggère qu'il attend quelque chose, sans presser.

072,6s · loop

Off-day

Yeux fermés en croissant. Quelques gouttes tombent au-dessus. Pour le carte "jour de repos", le panneau "Météo du corps" ou un Hooper bas.

085,4s · loop

Micro · header

Variante simplifiée pour les usages 24–32 px (indicateur de sync, toast, favicon dynamique). Pas d'orbite, pas de mouvement de pupille.

# Prompt d'implémentation — Mascotte Caillou

À coller dans Claude Code (ou autre agent dev) à la racine du projet ClaudeCode/.

## Contexte

Tu vas implémenter une mascotte visuelle nommée Caillou dans l'app Planif
Escalade (React 19 + Vite, design system custom dans src/theme/makeStyles.js).
La mascotte est un galet de bloc stylisé, animé en CSS pur, qui apparaît à des
moments calmes de l'app pour réchauffer les temps d'attente.

Règle d'or : la mascotte est purement visuelle. Aucun texte de l'UI ne lui
attribue d'intention, de mémoire ou de pensée. Elle ne parle pas, ne dit pas
"je m'en souviens", n'est jamais qualifiée de personnage. C'est un ornement
vivant — comme une plante sur un bureau.

## 1. Composant — src/components/Caillou.jsx

Crée un composant React fonctionnel avec la signature :

  <Caillou state="idle" size={120} />

Props
  state    "idle"|"sleep"|"loading"|"success"|"error"|"curious"|"rainy"|"micro"
  size     number, défaut 120 (largeur px, SVG carré viewBox 320×320)
  aria-label  string optionnel — si fourni: role="img"; sinon aria-hidden="true"

Comportement
- Pas d'état React interne.
- Animations CSS pures, déclenchées par la classe pebble pebble--{state}.
- Respecte @media (prefers-reduced-motion: reduce) → toutes animations off.
- success et error jouent leur animation une fois ; retour à idle au remount.
  Pour rejouer, le parent change une key=.
- Les couleurs viennent EXCLUSIVEMENT des CSS custom properties (--rock-1…).
  Pas de prop color, pas d'isDark dans le composant.

SVG + CSS
Le markup SVG complet (~80 lignes) et les keyframes sont dans la maquette
mascot/Caillou.html (sections Anatomie + Catalogue). Copie le SVG tel quel.
Mets les styles dans src/components/Caillou.css — pas dans makeStyles.js.

## 2. Tokens couleur — src/theme/makeStyles.js

Ajoute dans makeStyles(isDark), à côté des tokens existants :

  rock1:     D ? "#8d7960" : "#b8a484",
  rock2:     D ? "#6f5e49" : "#97836a",
  rock3:     D ? "#4d4032" : "#6c5b46",
  rockShine: D ? "#a89a82" : "#d8c9ad",
  rockEdge:  D ? "#2e251c" : "#5c4830",
  rockIris:  D ? "#1a1410" : "#2a2218",

Expose-les en CSS vars dans un wrapper autour du <Caillou>:
  <div style={{ '--rock-1': t.rock1, /* …etc */ }}><Caillou … /></div>

## 3. Points d'intégration

A. src/components/AuthPanel.jsx — magic link envoyé
   Quand sent === true: <Caillou state="curious" size={110}/> au-dessus du
   message "Lien envoyé — vérifiez vos mails". Pas de texte additionnel.

B. src/App.jsx (ou équivalent boot) — chargement initial Supabase
   Si le premier fetch dépasse 800 ms: <Caillou state="loading" size={160}/>
   centré, sous un texte sobre "Récupération de la semaine…". Fade-out 200 ms.

C. Empty state — semaine sans séance
   Quand weekSessions.length === 0 ET pas de métadonnées:
   <Caillou state="curious" size={130}/> au-dessus de "Aucune séance prévue".

D. src/components/AccueilView.jsx — carte du jour, jour de repos
   Quand isRestDay === true: <Caillou state="sleep" size={84}/> à gauche du
   greeting. Ne touche pas à getGreeting().

E. src/components/HooperSection.jsx — fatigue forte
   Si score Hooper en zone rouge: <Caillou state="rainy" size={72}/>
   discrètement dans la carte Hooper.

F. src/components/ToastContainer.jsx
   Toasts type "success": préfixe avec <Caillou state="success" size={28}/>
   à la place de l'icône ✓. Type "error": state="error", même taille.

G. Header (Dashboard.jsx) — sync long
   Pendant une sync > 1s: remplace le syncDot par <Caillou state="micro"
   size={24}/>. Le micro variant ne fait que respirer + cligner.

H. Modale feedback envoyé
   <Caillou state="success" size={100}/> centré au-dessus du titre.
   AUCUN texte n'évoque la mascotte.

## 4. Garde-fous

1. Jamais sur un écran de saisie active (création séance, BlockEditor).
2. Une mascotte visible à la fois maximum.
3. Pas avant 800 ms d'attente.
4. Pas de copy qui la personnifie. "Sauvegardé", "Aucune séance prévue", etc.
5. A11y: aria-hidden="true" par défaut. Le texte adjacent porte le sens.

## 5. Tests

- Rendu dans les deux thèmes (sombre/clair) sur chaque point d'intégration.
- prefers-reduced-motion: caillou immobile mais visible.
- Aucun layout shift à l'apparition/disparition (min-height ou aspect-ratio).
